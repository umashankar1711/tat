TAT Bilingual Website

Files:
- index.html : Tamil page
- en.html    : English page
- styles.css : shared theme and responsive styling
- script.js  : intro animation, mobile navigation and launch countdown

Language navigation:
Use the ENGLISH link in the Tamil page to open en.html.
Use the தமிழ் link in the English page to return to index.html.

Countdown:
Both pages count down ONLY to 11 December 2026 (midnight IST).
The November 17 date is the countdown start date, not a second countdown target.

Preview:
Open index.html or en.html in a browser.
Keep all four files in the same folder when hosting.
Before publishing, replace the data and gallery placeholders with approved TAT information and photographs.
